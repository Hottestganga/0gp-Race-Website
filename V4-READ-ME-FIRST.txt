HOW TO TEST
-----------
1. Back up your current website folder.
2. Extract this ZIP OVER the existing website project.
3. Stop any running dev server with Ctrl+C.
4. Delete the Next cache:
   Remove-Item -Recurse -Force .next
5. Start:
   npm.cmd run dev

Check:
http://localhost:3000/
http://localhost:3000/live
http://localhost:3000/history
http://localhost:3000/leaderboard
http://localhost:3000/docs

Then open a real active race from the Live Races page.

If you like this direction, the next upgrade can add genuine backend-persisted
race history, full-race graph data, Bank Value, biggest drops/flips and event
timelines instead of demo/locally observed data.
